# 因式鍊金術 Factor Alchemy

俾香港中二學生溫習因式分解嘅 3D 卡牌網頁遊戲，以《鋼之鍊金術師》做主題（等價交換、鍊成陣、賢者之石、真理之門）。
支援 Chromebook、iPad 同手機瀏覽器（橫向）。純靜態網站，唔需要 build step，可以直接部署去 Netlify。
學生記錄沿用「數學小島物語」同一套方式（同一個 Apps Script、同一個 Google Sheet、同一份學生資料 `mathverse-student`）。

> 美術全部係原創（程式畫嘅鍊成陣、齒輪、機械鎧紋理），冇用原作角色樣貌、官方 logo 或截圖；角色只用名字同原創出場對白。

### 改目標卡

```js
{ stars: 2, expr: 'xy + 2x + 3y + 6', answer: '(x + 3)(y + 2)' },
```

- `expr` 同 `answer` 可以寫 `x^2`、`x²`、`-`、`−`；`answer` 只可以係因式相乘，例如 `3x(x - 2)`、`2(x + 2)(x - 2)`、`(x + 3)^2`。
- 一次因式卡會由所有（包含星級嘅）標準答案自動生成，所以加目標卡唔使另外加因式卡。

### 啟動時自動驗證

遊戲一開就會檢查以下幾點，有錯會 throw error，畫面會顯示邊張卡出錯：
1. 每張目標卡嘅標準答案展開之後同目標一致。
2. 每個因式都係 primitive（係數 gcd = 1，首項係數正數），而且只係單項式或者一次式。
3. 牌組夠湊齊每一張目標卡（包括常數，例如 6 可以用 6 或者 2 × 3）。
4. 陷阱卡真係非 primitive。

## 兩種玩法

| | 簡易（預設） | 進階 |
| --- | --- | --- |
| 功能卡（逆鍊成、賢者之石、分解之手） | 冇 | 有 |
| 乘積錯 | 卡退返手，回合結束 | 卡退返手，仲要棄 1 張做代價 |
| 唔最簡（用咗陷阱卡） | 只棄走嗰張陷阱卡，並話你知應該點拆 | 5 秒截胡窗口，合成者出嘅卡全部棄掉 |
| 正確 | 即刻得分 | 先有 3 秒「分解之手」反應窗口 |
| 換牌 | 揀 1 張卡再按「換走呢張 · 結束回合」 | 「棄一抽一」掣 |
| 起手 / 手牌上限 | 8 張 / 10 張（滿咗就唔抽牌） | 6 張 / 8 張（超過要揀卡棄） |
| 勝利分數 | `winScoreSimple`（10） | `winScore`（15） |

第一次玩簡易玩法會自動彈出「點樣玩」說明，右上角 ? 掣隨時再睇。記錄入面 `rules` 欄會寫低用咗邊種玩法。

## 遊戲規則摘要（進階玩法）

- **開局**：揀 2 人或 4 人（1 個真人，其餘係電腦）、電腦難度、角色。桌面翻 4 張目標卡，每人起手 6 張因式組件卡；之後功能卡先洗入抽牌堆。
- **每個回合**：抽 1 張 →（可以）用逆鍊成 →（可以）揀 1 張目標 + 幾張手牌按「鍊成！」→ 冇鍊成可以「棄一抽一」→ 手牌上限 8 張。
- **合成判定**
  - 乘積錯：「等價交換失敗」，卡退返手，要棄 1 張做代價，回合結束。
  - 正確又最簡：3 秒反應窗口（分解之手），冇人打就得分。
  - 正確但唔最簡（用咗陷阱卡）：5 秒「分解不徹底！」，其他玩家可以揀一張能整除該因式 content 嘅常數卡（或賢者之石）截胡；揀錯卡就失去機會。合成者出嘅卡全部棄掉。
- **最簡因式組合**：乘積等於目標；每張一次因式 primitive；次序唔影響；重複因式出兩張；常數可以拆（6 = 2 × 3）。
- **功能卡**：逆鍊成（一次因式 +/− 互換）、賢者之石（當任意正整數常數）、分解之手（反應窗口強制展開，目標卡碎裂後退返桌面，合成者補抽同樣數量）。
- **真理之門**：一整輪冇人成功，換走桌面最舊嘅目標卡。
- **勝利**：先夠 15 分，或者目標卡用完時最高分。

## 教學功能

- 只用四種方法：提取公因式（★）、分組分解（★★）、平方差恆等式、完全平方恆等式（★★★，可以先抽公因式）。提示、驗算同檢討頁都會講明用咗邊種。
- 成功鍊成會有鍊成陣光柱、衝擊波、金色火花，再加一段「cut-in」：角色徽章、原創披風鍊金術師剪影同原創勝利對白（唔係原作角色樣貌）。撳一下畫面可以跳過。

- 每次成功合成彈出「驗算」：觀察 → 分解 → 驗算，逐步展開證明。
- 提示掣只講方法類別（公因式／分組分解／恆等式），每局 3 次。
- 完局檢討頁：所有出現過嘅目標卡同標準答案、玩家犯過嘅錯（乘積錯、唔最簡）同原因。
- 登入時揀中文 / English / 雙語，術語跟住顯示。

## 關卡、徽章同錯題本

- **4 個關卡 = 4 種方法**（`GAME.total = 4`）：提取公因式、分組分解、平方差恆等式、完全平方恆等式，每關 10 張目標卡。闖關時只出嗰種方法嘅題目，玩到目標卡用完；第一次就答對 `badgePass`（3）題或以上就得到徽章。集齊 4 枚就係「國家鍊金術師」。
- **綜合對戰**：四種方法混合，唔計徽章。
- **答錯唔扣分**：卡退返手上，畫面彈出提示（點解錯、呢種方法點做），按「👍 我明白了」先可以再揀卡再試。
- **獎勵**：第一次答對 = 分數 + 300 鈴錢；第二次答對 = 分數 + 150 鈴錢；第三次或以後先答對 = 目標卡清走，但冇分數、冇鈴錢（鼓勵再試，唔好亂試）。
- **錯題本**：答錯過嘅題目會自動記低。設定畫面「📒 錯題本」可以逐題重做（派返啱用嘅卡加干擾卡）；第一次就答對就算「改正」，+150 鈴錢並移出錯題本。

2. **學生資料**：只喺未有 `mathverse-student`（班別＋學號）時先出現；姓名選填。

## 夥伴、合成獸圖鑑同進化（參考 Pokémon：收集、夥伴、成長）

冇戰鬥數值、冇抽卡包，所有元素都同練習四種方法掛鈎。角色同合成獸美術全部係原創象徵圖案（機械鎧手臂、火花手套、瞄準鏡等），唔係原作角色樣貌；只用角色名字同原創對白。

**夥伴卡**：開局揀一位，每局可以用一次技能（「⚡」掣）。一開始有一男一女（阿姆斯特朗、溫莉），其餘靠闖關同錯題本解鎖。

| 夥伴 | 屬性（擅長方法） | 技能（每局一次） | 解鎖 |
| --- | --- | --- | --- |
| 阿姆斯特朗 | 提取公因式 | 肌肉鍊成：多抽 1 張，再棄 1 張 | 一開始 |
| 溫莉 | 分組分解 | 機械鎧調整：一次因式 +/− 互換 | 一開始 |
| 愛德華 | 提取公因式 | 合掌鍊成：換走 1 張手牌 | 「提取公因式」徽章 |
| 阿爾馮斯 | 分組分解 | 靈魂感應：偷看牌頂 2 張，揀 1 張 | 「分組分解」徽章 |
| 莉莎 | 平方差恆等式 | 鷹眼：免費睇目標卡用咩方法（記錄為 hint） | 「平方差恆等式」徽章 |
| 羅伊 | 完全平方恆等式 | 彈指：燒掉 1 張陷阱卡（要自己認出），再抽 1 張 | 「完全平方恆等式」徽章 |
| 伊兹密 | 完全平方恆等式 | 師父教誨：睇目標卡分解嘅第一步（記錄為 hint） | 錯題本改正 3 題 |

- **屬性（效果拔群）**：用擅長屬性嘅夥伴，第一或第二次答對嗰類題目，額外 +50 鈴錢（Lv3 +100）。
- **升級**：成功鍊成 5 次升 Lv2「國家鍊金術師」；15 次並取得該屬性徽章升 Lv3（二つ名，例如「鋼之鍊金術師」），卡框由普通 → 銀 → 金。
- **稀有度（閃卡）**：唔靠抽卡。一個關卡全部第一次答對（冇答錯）而且得到 3 題或以上，嗰位夥伴變閃卡。
- **合成獸圖鑑**：每完成一條目標式就收錄一隻原創合成獸（40 隻）同一張知識卡。外形同方法有關（獅＝提取公因式、鷲＝分組、鏡蛇＝平方差、雙頭熊＝完全平方），角數＝星級，眼數＝要用幾多張因式卡。
- **進化**：答對之後，目標式會一步步「進化」成最簡因式，例如 5x² − 20 → 5(x² − 4) → 5[x² − 2²] → 5(x + 2)(x − 2)，再收錄入圖鑑。撳一下可以跳過。
- 設定喺 `CONFIG.partnerLevelUses / partnerTypeBonus / notebookUnlock`；資料存喺 `factor-alchemy-v1`（`partners`、`shiny`、`dex`），唔會改動成績記錄嘅事件同欄位。

## 學生記錄（同數學小島物語一樣）

- 學生資料：`localStorage['mathverse-student']`（`{cls, no, name}`），所有 mathverse 遊戲共用；已有資料會自動填好，唔使再輸入。班別同學號必填，姓名選填。
- 進度存檔：`localStorage['factor-alchemy-v1']`；每次存檔都會 `hubSync()`，更新 `localStorage['mathverse-hub'].games['factor-alchemy']`，主頁可以讀到徽章同鈴錢。
- 傳送：`navigator.sendBeacon`（`text/plain`），失敗就改用 `fetch(…, { mode: 'no-cors', keepalive: true })`。喺 claude.ai 預覽（`window.claude` 存在）唔會傳送。
- 每筆都帶：`v:2, game, badgeTotal, sid, cls, no, name, ev, bells, badges, t, dev`。

| ev | 幾時傳 | 額外欄位 |
| --- | --- | --- |
| `start` | 開始第一局（或錯題本練習）時 | — |
| `heartbeat` | 每 60 秒；只喺頁面可見而且 2 分鐘內有操作 | — |
| `answer` | 每次按「鍊成！」 | `place`（common / group / diffSq / perfSq / mixed / notebook）、`qid`（例如 d03）、`topic`、`ok`、`attempt`、`first`、`hint`、`secs`（揀目標卡至作答，上限 600；答錯後按「我明白了」重新計時）、`review`、`fixed` |
| `hint` | 用提示卡 | `qid`、`topic` |
| `house_result` | 完成一個關卡 | `place`、`topic`、`score`（第一次答對數）、`total`、`badge`、`newBadge` |
| `win` | 集齊 4 枚徽章 | — |

## 效能

- 鏡頭固定，CSS3D 只喺有變化嗰陣先重畫；燭光用 2 盞點光源；冇陰影。
- 右上角 ⚡ 掣係「簡化特效」：關閉閃電、碎片、塵埃同燭光閃爍，降低解像度。開局 4 秒內如果偵測到幀率太低會自動開啟。
- 設定（靜音、簡化特效、上次揀嘅角色）、學生資料同進度都記喺 localStorage，所有讀寫都有 try/catch，私密瀏覽模式都玩得。
