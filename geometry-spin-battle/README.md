# 幾何陀螺對戰 Geometry Spin Battle — 開發及使用指南

一個以 **Three.js 3D 陀螺對戰** 包裝的數學教育遊戲，教授 **「與直線圖形相關的角」**，並融入 **生命教育**（堅韌不拔、尊重與規則、個人獨特性）。成績會經 **Google Apps Script** 寫入老師的 Google Sheet。

| 檔案 | 用途 |
|---|---|
| `index.html` | 完整遊戲（HTML + CSS + JavaScript，單一檔案，所有程式都有中文註解） |
| `Code.gs` | Google Apps Script 後端（`doPost(e)` 接收成績並寫入 Google Sheet） |
| `README.md` | 本指南 |

> 遊戲名稱刻意用了通用名稱「幾何陀螺對戰」，陀螺造型亦為原創，避免使用任何商標角色或設計。如需改名，修改 `index.html` 內的 `<title>` 及開場畫面文字即可。

---

## 1. 快速開始（5 分鐘）

1. **設定 Google Sheet**（見第 2 節），取得 Web App 網址。
2. 打開 `index.html`，找到最上方的設定：
   ```js
   const CONFIG = {
     GAS_URL: 'PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE',
     TOTAL_ROUNDS: 5, QUESTION_TIME: 60, ...
   };
   ```
   把 `GAS_URL` 換成你的網址（以 `/exec` 結尾）。
3. 把 `index.html` 放上任何網頁空間，例如 **GitHub Pages**、Google Sites（嵌入）、學校內聯網；或直接用 Chrome / Edge 打開檔案亦可遊玩。
   - 測試時亦可在網址後加 `?gas=你的網址`，毋須修改檔案。
4. 未設定網址時，遊戲以「示範模式」運行，可完整遊玩，只是不會上傳成績。

**瀏覽器要求：** 支援 WebGL 的現代瀏覽器（Chrome、Edge、Safari、Firefox；iPad / 手機亦可）。需要網絡載入 Three.js（cdnjs）。

## 2. Google Apps Script：綁定 Google Sheet

1. 在 Google Drive 建立一個新的 **Google 試算表**（例如命名為「幾何陀螺成績」）。
2. 在試算表選單按 **擴充功能 (Extensions) → Apps Script**。
   - 用這個方法建立的 Apps Script 會**自動綁定**這個試算表，程式中的 `SpreadsheetApp.getActiveSpreadsheet()` 就是它。
3. 刪除編輯器內的預設程式，把 **`Code.gs` 全部內容**貼上，按 💾 儲存。
4. （建議）在上方函數選單揀 `testDoPost` → 按 **執行**。第一次會要求授權：選你的帳戶 → 「進階」→「前往（不安全）」→「允許」。回到試算表，應見到新工作表 **Scores** 及一行測試資料。
5. 按右上角 **部署 (Deploy) → 新增部署作業 (New deployment)**：
   - 齒輪圖示 → 類型揀 **網頁應用程式 (Web app)**
   - 執行身分 (Execute as)：**我 (Me)**
   - 具有存取權的使用者 (Who has access)：**任何人 (Anyone)**（學生毋須登入 Google）
6. 按 **部署**，複製 **網頁應用程式網址**（`https://script.google.com/macros/s/……/exec`）。
7. 在瀏覽器打開這個網址，看到 `{"result":"ok", ...}` 即代表部署成功。
8. 把網址貼到 `index.html` 的 `CONFIG.GAS_URL`。

> ⚠ **修改 `Code.gs` 後**：要到「部署 → 管理部署作業 → ✏️ 編輯 → 版本：**新版本** → 部署」，新程式才會生效（網址不變）。

### Google Sheet 欄位

| 時間 | 姓名 | 班別 | 學號 | 分數 | 答對題數 | 總題數 | 勝出回合 | 補救題答對 | 發射角度 | 語言 | 語音 | Submission ID |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

### 前端如何傳送資料（Fetch API）

```js
const payload = { name, className, classNo, score, correct, total, roundsWon,
                  remedialCorrect, launchAngles, language, voice, submissionId };
const res = await fetch(CONFIG.GAS_URL, {
  method: 'POST',
  headers: { 'Content-Type': 'text/plain;charset=utf-8' },  // 重點：避免 CORS preflight
  body: JSON.stringify(payload)
});
const data = await res.json();   // { result: 'success', row: 12 }
```

- 為何用 `text/plain` 而不是 `application/json`？`application/json` 會令瀏覽器先送 `OPTIONS` 預檢請求，Apps Script 不支援，會被 CORS 擋住。`text/plain` 屬「簡單請求」，內容仍然是 JSON，Apps Script 以 `e.postData.contents` 讀取。
- 若學校網絡令瀏覽器讀不到回覆，遊戲會自動改用 `mode: 'no-cors'` 再送一次；因為每場比賽有唯一的 `submissionId`，Apps Script 會**自動略過重複記錄**。
- `Code.gs` 亦有 `LockService`（多人同時提交不會互相覆蓋）及「公式注入」防護。

## 3. 遊戲流程

```
語言選擇（繁中 / English / 中英對照）
   → 語音導覽選擇（廣東話 / 英文 / 普通話 / 不需要）
   → 學生資料登記（姓名、班別、學號、陀螺顏色）
   → 第 1–5 回合：
        ① 發射題（數學解題，限時 60 秒）
        ② 發射（答案 = 發射角度，即地上截線的角度）
        ③ 3D 對戰（碰撞、火花、音效、衝擊鍵）
        ④ 若轉速過低 / 被撞至傾斜 → 「堅韌不拔」訊息 + 補救幾何題
        ⑤ 回合結果
   → 比賽結束：尊重與規則（雙方回到中央互相致意）
   → 個人獨特性（俯視所有回合的彩色軌跡）
   → 結算 + 上傳成績
```

### 數學 → 對戰的連結

| 答題表現 | 效果 |
|---|---|
| 答對 | 發射轉速 3600–5400 RPM（越快越高）、攻擊力 ×1.1–1.6、**幾何護盾**（減少擊退及轉速損失，被撞數次後破裂） |
| 答錯 / 超時 | 只有 2000 RPM、攻擊力 ×0.75、沒有護盾 → 容易被撞飛 |
| 補救題答對 | 找回重心：轉速回升、扶正、重新獲得護盾 |

**計分：** 答對 100 分 + 速度加分最多 50 分；補救題 30 分；勝出 100 分、平手 50 分。全部可在 `CONFIG` 修改。

**競技場設計：** 平面競技場地面畫有兩條平行線 L₁ // L₂（全部是直線，不涉及曲線或圓的角）。學生答案會成為**發射角度 θ**，地上會畫出一條以 θ 與平行線相交的**截線**，並在兩個交點標示相等的同位角，學生的陀螺就沿這條截線發射。

## 4. 題目設計（對應課題「與直線圖形相關的角」）

所有題目由程式**隨機生成**，數字每次不同、答案必為整數，圖形按真實角度繪畫（已自動化測試 14 種題型各 3000 次，圖中量得的角度與答案一致）。

| 回合 | 題型 | 涉及的幾何性質 |
|---|---|---|
| 1 | 三角形內角和、等腰三角形底角、平行線（同位角／內錯角／同旁內角／對頂角／鄰角） | ∠ sum of △、base ∠s, isos. △、corr. / alt. / int. ∠s |
| 2 | 三角形外角、等腰三角形 + 外角 | ext. ∠ of △、adj. ∠s on st. line |
| 3 | 多邊形內角和、多邊形外角和、正多邊形（求內角 / 外角 / 邊數） | ∠ sum of polygon、sum of ext. ∠s of polygon |
| 4 | 等邊 + 等腰三角形、以 x 表示的三角形內角（簡易方程）、綜合題 A | prop. of equil. △ |
| 5 | 綜合題 A / B / C（附件 DSE 題型改編） | 多步推理 |
| 補救題 | 一步題：三角形內角和、直線上的鄰角、等腰三角形、平行線 | — |

**綜合題與附件題目的對應：**
- 綜合題 A ← 附件第 1 題（PT // RS，RS = RQ，求 ∠PQR）
- 綜合題 B ← 附件第 2、3 題（PQ = QR，PQ // RS，求 ∠RPT）
- 綜合題 C ← 附件第 14 題（AD = CD = CB，∠BCE = 3x）
- 正多邊形 ← 附件第 23 題（內角和 / 外角 / 邊數）

**已剔除（按要求，或不屬本課題）：** 所有涉及**比 / 比例**的題目（附件第 9、34、35 題等）、**相似三角形**（第 13、18–22、24、25、38、39 題）、**畢氏定理及面積／周界**（第 4–8、12、15、30–33、36、37 題）、全等三角形證明題。附件第 10 題（「內角是外角的 17 倍」）屬倍數關係，為穩妥起見亦未採用。

**新增題型：** 在 `index.html` 的 `GEN` 物件加入一個函數（回傳 `mkQ(...)`），再把名稱放進 `ROUND_POOLS` 即可。`Fig` 類別提供 `pt / seg / ang / tick / par` 繪圖工具。

## 5. 生命教育元素

| 元素 | 觸發時機 | 呈現 |
|---|---|---|
| **堅韌不拔 Resilience** | 對戰中玩家陀螺轉速跌至發射轉速 38% 以下，或被撞至明顯傾斜（每回合一次） | 戰鬥暫停，語音 + 文字：「生活就像陀螺，遇到挫折失去平衡在所難免，但只要找回重心（重新計算正確角度），就能重新站立旋轉！」，並給一題補救幾何題 |
| **尊重與規則 Respect & Rules** | 比賽結束（無論勝負） | 雙方陀螺回到中央、互相傾側「鞠躬」致意；顯示並朗讀：「平行的軌跡雖然不相交，但彼此尊重（平行線的規則）；交匯的瞬間（截線）則創造了獨特的角度（人生火花）。」 |
| **個人獨特性 Uniqueness** | 尊重訊息之後 | 鏡頭轉為俯視，地上同時顯示學生每回合的截線（發射角度）及彩色軌跡；陀螺上印有學生名字首字；朗讀「每個陀螺（每位同學）都有屬於自己的發射角度……天生我才必有用！」 |

## 6. 語音（Web Speech API）

- 使用瀏覽器內置的 `speechSynthesis`，毋須任何 API key。
- 廣東話 = `zh-HK`、普通話 = `zh-CN`、英文 = `en-GB`。程式會自動揀選裝置上最合適的聲音。
- 數學符號會轉成可朗讀文字（∠ → 「角」、△ → 「三角形」、° → 「度」、// → 「平行於」）。
- **廣東話語音：** Windows 需安裝「中文（香港）」語音套件；iPad / iPhone / Mac 及大部分 Android 已內置。若裝置沒有該語音，語音選擇畫面會顯示提示，並改用系統預設聲音。
- 遊戲中右上角 🔊 可開關語音、🎵 可開關音效；題目旁 🔈 可重讀題目。

## 7. 技術說明（給開發者）

- **3D：** Three.js r128（`cdnjs` UMD 版本）。競技場中央是**完全平坦**的平面（半徑 8.5），只有最外圈有少許斜邊；所有平行線、截線及角度都只畫在平面區內，所以從任何角度看都是直線（中二學生未學過曲線的角）。地面方格亦只用直線。發射倒數時鏡頭轉為俯視，令發射角 θ 以真實大小顯示。地面是 `CanvasTexture`，可即時重畫截線及角度。陀螺由圓錐、圓柱、擠出形狀（攻擊刃）組成，並有旋轉模糊環及六角柱「幾何護盾」。
- **物理：** 簡化 2D 物理（向心斜面力、旋轉切向漂移形成花瓣軌跡、電腦 AI 追擊、牆壁反彈 / 撞出場外、轉速衰減、低轉速傾斜搖擺）。碰撞計算擊退、轉速損失及傾斜，並放出火花粒子、閃光及鏡頭震動。
- **音效：** Web Audio API 即時合成（碰撞金屬聲、發射、倒數、勝負音樂、隨轉速變化的嗡嗡聲），不需外部音檔。
- **除錯：** 在瀏覽器 Console 輸入 `__game.G.q.answer` 可看到目前題目的答案（方便老師示範）。
- **回應式設計：** 桌面版題目面板在右邊（3D 畫面自動左移）；手機版面板在底部。

## 8. 常見問題

| 問題 | 解決方法 |
|---|---|
| 成績沒有寫入 Sheet | 確認部署時「存取權」是 **任何人**；修改程式後有否部署 **新版本**；在瀏覽器直接打開 `/exec` 網址檢查。 |
| 顯示「示範模式」 | `CONFIG.GAS_URL` 尚未設定，或網址不是 `https://script.google.com/...` 開頭。 |
| 沒有聲音 | 部分瀏覽器要求先與網頁互動才可發聲（遊戲已在按「語言」按鈕時啟動音效）；檢查 🔊 / 🎵 是否開啟。 |
| 3D 畫面空白 | 瀏覽器未啟用 WebGL / 硬件加速，或無法連接 cdnjs.cloudflare.com。 |
| 想縮短遊戲時間 | 把 `CONFIG.TOTAL_ROUNDS` 改為 3，或縮短 `QUESTION_TIME` / `BATTLE_TIME`。 |
